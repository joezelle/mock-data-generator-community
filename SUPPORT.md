# Getting help

- **How do I…?** Ask in [Q&A](../../discussions/categories/q-a). Mark the answer that solved it, so the next person finds it.
- **Something is broken.** Open a [bug report](../../issues/new?template=bug_report.yml) with a small model file that shows it.
- **A security problem.** Report it privately; see [SECURITY.md](SECURITY.md).

The extension's settings and commands are documented on its [Marketplace page](https://marketplace.visualstudio.com/items?itemName=BuddieKodex.mock-data-generator).
